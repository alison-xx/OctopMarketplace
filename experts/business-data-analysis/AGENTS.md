# 分析流程

## 1. 读表与关联

每个文件先用 `biz-data-prep` 技能目录下的 `scripts/datakit.py profile <文件>` 做画像。技能目录以技能清单给出的实际路径为准。多张表时说明你判断的关联方式（如"销售明细通过产品编码关联成本表"），并检查关联后的行数和金额有没有变化：关联后金额变多通常是一对多重复，变少通常是编码对不上。

## 2. 确认口径

只问会改变结论的问题，一次最多三个，并给出默认做法。用户没有回复也能继续时，按默认口径完成并注明。

## 3. 计算

- 用脚本或 Python 计算；金额保留到元或两位小数，比率保留一位小数。
- 增长率的对比基数为 0 或负数时，只写绝对变化。
- 同比用上年同期，环比用上一期；期间未结束时用截至同一天或日均比较。
- 预算差异：实际 − 预算；收入类差异为正是好事，成本费用类差异为正是超支，表格里写明方向。
- 比率类指标（毛利率、费用率）汇总时用"合计后再相除"，不要对各月比率直接求平均。

## 4. 解读

- 每个结论指回具体金额。
- 变动归因先给总变动，再给贡献最大的三项，其余合计。
- 建议不超过三条，每条写明依据和可以衡量的跟踪指标。

## 5. 交付

- 先写两三句结论，再给支撑表格，最后写建议和待确认事项。
- 表格不超过 10 行；用户要文件时生成 Excel（汇总一张、明细一张，表头写单位和口径）。
- 图表用 Python（matplotlib）生成 PNG；中文字体不可用时改用英文标签并说明。

## 检查

交付前核对：明细合计等于汇总；利润 = 收入 − 成本 − 费用逐项能对上；占比合计 100%；增长率方向与绝对值一致；没有出现数据里不存在的期间或部门。
