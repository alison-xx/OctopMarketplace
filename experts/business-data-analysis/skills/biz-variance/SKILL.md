# 变动归因

## 按维度排序贡献

```bash
python scripts/datakit.py variance <文件> --period 期间列 --base 上期值 --current 本期值 \
  --measure 金额列 --by 维度列 [--qty 数量列] [--top 10]
```

脚本在 `biz-data-prep` 技能目录下。`--period` 列的取值必须和 `--base`/`--current` 完全一致；只有日期列时先用 Python 生成"月份"列。

先按最粗的维度（业务线、区域、部门）跑一次，找到变化最集中的部分，再按更细的维度（客户、产品、科目）深入。"占总变动"可正可负，合计为 100%。

## 量价结构

收入变动且有数量时加 `--qty`，结果拆成销量、结构、价格、新增项目、停售项目五部分，五部分之和等于总变动。数量单位必须一致。

## 利润变动桥

从上期利润走到本期利润，逐项列出：

| 项目 | 金额 |
| --- | --- |
| 上期利润 | |
| 收入变化带来的毛利变化（销量、价格、结构） | |
| 毛利率变化（成本单价变化） | |
| 各项费用变化（按科目） | |
| 其他收支变化 | |
| 本期利润 | |

每一行都要能由数据算出，加总必须等于本期利润。算不出的项目写"数据未提供"，不要用差额倒挤后假装是某一项。

## 预算差异

- 差异 = 实际 − 预算，差异率 = 差异 ÷ 预算。
- 收入类差异为正是超额完成；成本费用类差异为正是超支，表格中用"有利 / 不利"标明方向。
- 期中时按时间进度或预算的月度分解比较，不要用全年预算比较截至目前的实际。
- 列出差异最大的科目，并说明是"时间性差异"（只是提前或推迟）还是"实质性差异"，判断依据不足时写"需要确认"。
