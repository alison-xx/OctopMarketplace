# 读表、关联与口径

## 数据画像

```bash
python scripts/datakit.py profile <文件> [--sheet 工作表名]
```

`scripts/` 相对于本技能目录。只依赖 Python 标准库，读 `.xlsx` 需要 `openpyxl`。脚本自动跳过标题行，识别 UTF-8 / GBK 编码，把"￥1,200""12%""(300)"识别为数字，并列出每列的类型、空值、取值范围和完全重复的行数。

一个 Excel 有多个工作表时，先列出工作表名，再逐个画像；"说明""封面"等工作表可以跳过。

## 常见数据与关键字段

| 数据 | 关键字段 | 注意 |
| --- | --- | --- |
| 销售 / 收入 | 日期、客户、产品、数量、金额、税额 | 含税与不含税；退货冲减 |
| 采购 / 成本 | 日期、供应商、产品、数量、单价、金额 | 单位与销售是否一致 |
| 费用 | 日期、部门、科目、金额 | 科目名称是否统一；是否含个人报销明细 |
| 库存 | 产品、仓库、数量、成本单价、入库日期 | 是期末快照还是流水 |
| 应收 / 应付 | 客户或供应商、单据日期、到期日、金额、已收已付 | 是否已核销 |
| 预算 | 期间、部门或科目、预算金额 | 与实际的科目口径是否一致 |

## 关联

- 优先用编码关联（产品编码、客户编码），名称只用于展示。
- 关联前统一格式：去掉首尾空格、全半角统一、编码前导零。
- 关联后核对行数和金额：变多说明有一对多重复，变少说明有编码对不上；把对不上的记录列出来请用户确认。

## 清洗

处理前后都记录行数和金额：重复导出、退货与红冲、测试与内部单据、空值。处理方式写进回答里的口径说明，不静默删除数据。

## 数据字典

用户需要长期使用时，整理一份数据字典：每张表的用途、字段含义、口径、更新频率。用 Markdown 表格或 Excel 交付。
