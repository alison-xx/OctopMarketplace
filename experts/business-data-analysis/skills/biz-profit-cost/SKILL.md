# 利润与成本费用

## 毛利

| 指标 | 公式 |
| --- | --- |
| 毛利额 | 收入 − 销售成本 |
| 毛利率 | 毛利额 ÷ 收入 |
| 毛利贡献 | 某业务毛利额 ÷ 总毛利额 |

- 按产品、客户、渠道、区域分别看毛利额和毛利率，找出"收入高、毛利低"和"毛利率为负"的部分。
- 成本口径（采购价、加权平均、是否含运费和损耗）问清或写明。
- 毛利率汇总时用合计毛利 ÷ 合计收入，不对各项毛利率直接平均。

## 费用

- 按科目汇总，计算费用率（费用 ÷ 收入），看结构和趋势。
- 区分固定费用（房租、固定工资、折旧）和变动费用（提成、运费、平台佣金）。分类由数据和用户确认，不确定的科目单独列出。
- 费用突然变化时，查看明细中金额最大的几笔，说明是一次性支出还是持续性增加。

## 盈亏平衡

```
盈亏平衡收入 = 固定成本 ÷ 边际贡献率
边际贡献率 = （收入 − 变动成本）÷ 收入
安全边际 = （实际收入 − 盈亏平衡收入）÷ 实际收入
```

固定和变动成本的划分是估计，结果要写明划分方式，并给出"变动成本率上下浮动几个百分点时"的结果范围。

## 客户与产品盈利

有足够数据时，把直接费用（如某渠道佣金、某客户专属运费）分摊到对应的客户或产品上，计算贡献利润。分摊规则写明；没有依据的间接费用不要随意分摊，单独列出。
