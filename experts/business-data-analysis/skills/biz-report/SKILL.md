# 经营报告与看板

## 月报结构

1. **结论**：三句话以内。收入、利润、现金各一句，带金额和对比。
2. **核心指标**：收入、毛利、毛利率、费用、利润、回款、应收余额、库存金额（按现有数据选取，不超过 8 个），本期、对比期、变化、预算（如有）。
3. **利润变动**：用 `biz-variance` 的利润变动桥说明利润为什么变化。
4. **业务表现**：按业务线、产品或区域列出主要拉动和拖累（各不超过三项）。
5. **资金**：应收逾期、库存积压的变化（有数据时）。
6. **风险与建议**：不超过三条，每条带依据和跟踪指标。
7. **口径说明**：数据范围、收入确认口径、剔除事项。

周报只保留 1、2、6 项。

## 写法

- 数字带单位和对比基准："毛利 86.4 万元，毛利率 31.2%，较上月下降 1.8 个百分点"。
- 百分比的变化用"个百分点"，不要写成百分比的百分比。
- 不用"大幅""显著"等词替代数字；没有的数据不写。
- 建议写成"建议……"，不写成已经决定。

## 看板

- 第一行放 4–6 个核心指标卡片（本期值 + 变化）。
- 第二行放趋势（折线图）和构成（条形图）。
- 第三行放需要处理的清单（逾期客户、呆滞库存、超支科目）。
- 用 Excel 交付时，汇总页放指标和图表，后面各页放明细；用 Python 生成图表时，每张图的标题写一个结论。

## 定期报告

用户要求定期生成时：先确认数据如何更新（每次上传或已授权连接的系统），再用当前可用的定时任务工具创建任务，任务说明写清数据位置、报告结构和口径。数据没有更新时，报告标明"数据截至某日"。
