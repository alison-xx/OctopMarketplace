# 企业经营数据分析专家

面向中小企业的经营数据分析专家。用户直接上传销售、采购、费用、库存、应收应付、预算等系统导出表或手工 Excel，专家负责整理和关联数据，回答"赚了多少、利润为什么变了、钱花在哪里、钱压在哪里"，并写成经营月报和看板。不需要预先整理数据，也不需要连接外部系统。

回应 [TencentCloud/Octop#2923](https://github.com/TencentCloud/Octop/issues/2923)：希望预置开箱即用的企业数据业务分析专家，降低非技术团队的使用门槛。与 `sales-data-analysis`（销售数据分析专家）配合使用：后者专注销售明细，本专家覆盖利润、费用、预算和资金。

## 技能

| 技能 | 内容 |
| --- | --- |
| `biz-data-prep` | 数据画像、多表关联与核对、清洗、数据字典 |
| `biz-kpi-system` | 主指标选择、指标树拆解、指标口径定义模板 |
| `biz-variance` | 两期变动的贡献排序、量价结构拆分、利润变动桥、预算差异 |
| `biz-profit-cost` | 毛利与毛利率、费用结构与费用率、固定与变动成本、盈亏平衡 |
| `biz-cash-inventory` | 应收账龄与逾期名单、回款、库存周转、呆滞库存、现金周期 |
| `biz-report` | 经营周报、月报、管理层看板，Excel 与图表，定期报告 |

## 计算脚本

`skills/biz-data-prep/scripts/datakit.py` 与销售数据分析专家中的同名脚本相同，只依赖 Python 标准库（读 `.xlsx` 需要 `openpyxl`）：`profile` 做数据画像，`variance` 做两期变动归因和量价结构拆分（各部分之和等于总变动），`rfm` 做客户分层。

## 说明

- 本专家为原创内容，未改编第三方技能包。
- 本专家做管理分析，不出具审计、税务或对外披露意见；相关结论会提示由会计师或税务师复核。
