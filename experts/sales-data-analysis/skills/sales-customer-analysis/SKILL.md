# 客户分析

## RFM 分层

RFM 用三个数给客户分层：R＝最近一次购买距今多少天（越小越好），F＝购买次数，M＝购买金额。

```bash
python scripts/datakit.py rfm <文件> --customer 客户列 --date 日期列 --amount 金额列 \
  [--order 订单号列] [--asof 2026-10-31] [--out 客户分层.csv]
```

脚本在 `sales-data-intake` 技能目录下。有订单号时一定传 `--order`，否则一单多行会被算成多次购买。`--asof` 默认取数据里最后一笔交易日；分析"截至今天"时传当天日期。

脚本按每个指标的全体客户均值分高低，得到八类客户：

| 分层 | 特征 | 常见动作（建议） |
| --- | --- | --- |
| 重要价值客户 | 近期买过、买得多、金额大 | 维护关系，优先服务 |
| 重要保持客户 | 买得多、金额大，但最近没买 | 尽快回访，了解原因 |
| 重要发展客户 | 近期买过、金额大，但次数少 | 推动复购 |
| 重要挽留客户 | 金额大，但很久没买、次数少 | 判断是否已流失，决定是否挽回 |
| 一般价值 / 保持 / 发展 / 挽留客户 | 金额低于均值 | 批量运营，控制投入 |

分层基于均值，少数大客户会拉高均值；客户金额差异很大时，可以改用中位数或分位数在 Python 里重算，并说明原因。

## 其他分析

- **客户贡献与集中度**：按销售额排序，前 10 名和前 20% 客户的销售额占比。占比过高说明依赖大客户，单个客户流失影响大。
- **新老客户**：以分析期之前是否买过区分新客户和老客户，分别看客户数和销售额。需要分析期之前的数据，没有就说明无法区分。
- **复购率**：期内购买 2 次及以上的客户 ÷ 期内购买客户数。次数按订单号去重。
- **沉睡与流失预警**：根据客户自己的平均购买间隔判断，"超过平均间隔两倍未下单"比固定天数更合理。列出预警名单时附上最近购买日、历史金额和负责销售。
- **客单价与购买频次分布**：分档统计，找出可提升的客户群。

- 客户名单含联系人等个人信息时，只在用户需要时输出，不写进长期记忆。
