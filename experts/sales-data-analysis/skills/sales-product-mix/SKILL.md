# 产品结构与毛利

## ABC 分类

按销售额从高到低累计：累计占比到 70% 的为 A 类，70%–90% 为 B 类，其余为 C 类。分别给出每类的产品数、销售额占比。A 类是重点保障的品，C 类里长期没有销量的品是清理候选。

分类标准可以按用户习惯调整（如 80/15/5），在结果里写明。也可以按毛利额分类，与按销售额分类对照，找出"卖得多但不赚钱"的品。

## 毛利

| 指标 | 公式 |
| --- | --- |
| 毛利额 | 销售额 − 成本 |
| 毛利率 | 毛利额 ÷ 销售额 |
| 毛利贡献 | 某产品毛利额 ÷ 总毛利额 |

只有数据里有成本或用户提供了单位成本才算毛利。成本口径（采购价、加权平均成本、含不含运费）问清或写明。毛利率为负的产品单独列出。

## 量价结构拆分

销售额变化可以拆成：销量变化、产品结构变化（高价品卖得多还是低价品卖得多）、同一产品的价格变化，以及新上市和停售的产品。

```bash
python scripts/datakit.py variance <文件> --period 月份列 --base 上期 --current 本期 \
  --measure 金额列 --by 产品列 --qty 数量列
```

脚本在 `sales-data-intake` 技能目录下。解读示例：

- 销量影响为正、价格影响为负：卖得更多，但靠降价；
- 结构影响为正：高价产品的销量占比提高；
- 新增项目影响大：增长主要来自新品。

数量单位必须一致；同一产品既有件又有箱时先换算。

## 滞销

结合最近销售日期和库存（如有）：长期无销量、有库存的产品列为滞销候选。只有销售数据时只能说"近 N 天无销售"，不能断言有库存积压。
