# 读表与口径确认

## 数据画像

```bash
python scripts/datakit.py profile <文件> [--sheet 工作表名]
```

`scripts/` 相对于本技能目录。脚本只依赖 Python 标准库，读 `.xlsx` 需要 `openpyxl`。它会：

- 自动跳过表头前的标题行和空行（常见于"2026年10月销售明细"这类导出）；
- 自动识别 UTF-8、GBK 编码和逗号、制表符分隔；
- 把"￥1,200""12%""(300)"这类文本识别为数字；
- 列出每列的类型、空值数、不同取值数、范围或常见取值，以及完全重复的行数。

画像结果是推断，用来决定下一步，不必原样贴给用户。

## 识别字段

| 角色 | 常见列名 | 判断依据 |
| --- | --- | --- |
| 日期 | 下单时间、开票日期、发货日期、日期 | 日期类型；多个日期列时问清按哪个统计 |
| 订单号 | 订单编号、单号、单据号 | 文本、取值多且有重复（一单多行） |
| 客户 | 客户名称、客户编码、买家、门店 | 文本，取值数远少于行数 |
| 产品 | 商品名称、SKU、物料、品名、规格 | 文本 |
| 销售人员 | 业务员、销售、负责人 | 文本，取值数少 |
| 数量 | 数量、件数、销量 | 数值，多为整数 |
| 金额 | 金额、销售额、实收、成交金额、价税合计 | 数值，与数量×单价近似 |
| 成本 | 成本、成本金额、进价 | 数值，通常小于金额 |
| 状态 | 订单状态、是否退货、单据类型 | 文本，取值数很少 |

同时有"金额"和"价税合计"时，前者多为不含税。有客户编码就用编码识别客户，名称只用来展示，避免同名或简称不一致。

## 清洗

用 Python 处理，处理前后都记录行数和金额：

1. **重复行**：完全重复的行先问是否为重复导出；同一订单号出现多行通常是一单多品，不是重复。
2. **退货与取消**：状态为退款、退货、取消，或金额为负数的行，按用户口径冲减或剔除，默认冲减（净额）。
3. **测试与内部单**：客户名含"测试""内部"等的行，列出来请用户确认，不要直接删除。
4. **空值**：缺客户或缺金额的行不进入对应分析，并报告数量。
5. **口径统一**：同一客户的不同写法（如"华星科技"和"华星科技有限公司"）列出疑似重复让用户确认；数量单位混用时先换算。

## 交付给后续分析

用一两句话告诉用户你理解的数据：时间范围、行数、订单数、客户数、产品数、净销售额，以及采用的口径和剔除情况。然后继续用户真正要的分析。
