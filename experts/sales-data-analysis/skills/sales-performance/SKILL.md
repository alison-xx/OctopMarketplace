# 业绩与目标达成

## 常用指标

| 指标 | 公式 | 需要的字段 |
| --- | --- | --- |
| 销售额 | 金额合计（净额） | 金额 |
| 订单数 | 订单号去重计数 | 订单号 |
| 客单价 | 销售额 ÷ 订单数 | 金额、订单号 |
| 成交客户数 | 客户去重计数 | 客户 |
| 目标达成率 | 实际 ÷ 目标 | 目标值（用户提供） |
| 时间进度 | 已过天数 ÷ 期间总天数 | 日期 |
| 同比 / 环比 | （本期 − 对比期）÷ 对比期 | 两期数据 |
| 贡献占比 | 某维度销售额 ÷ 总销售额 | 维度字段 |

## 做法

1. **趋势**：按月（数据少于两个月时按周或按日）汇总销售额、订单数、客单价，看是量的变化还是客单价的变化。
2. **对比**：有上年同期就算同比，有上一期就算环比；本期未结束时按截至同一天的同期比较，或比较日均。
3. **目标**：用户给了目标才算达成率。期中时同时给出时间进度，"达成率 45%、时间进度 60%"比单独一个达成率更有用。可以按当前日均推算期末预计完成值，并写明这是推算。
4. **排名**：按销售人员、区域、渠道等维度排名，给出销售额、占比、同比或环比。只看前几名时注明其余合计。
5. **集中度**：前 20% 的销售人员或客户贡献了多少，帮助判断是否过度依赖少数人。

## 变化归因

业绩增长或下滑时，用 `sales-data-intake` 技能目录下的脚本找出变化来自哪里：

```bash
python scripts/datakit.py variance <文件> --period 月份列 --base 2026-09 --current 2026-10 --measure 金额 --by 销售人员
```

`--period` 列的取值必须和 `--base`/`--current` 一致；原始数据只有日期时，先用 Python 生成"月份"列再运行。按不同维度（区域、产品、客户）各跑一次，找到变化最集中的维度再深入。

## 注意

- 不同销售人员负责的客户或区域不同时，排名只反映结果，不直接等于能力，结论里要说明。
- 提成和考核口径（回款还是下单、含税还是不含税）以公司制度为准，用户没说明时提示确认。
