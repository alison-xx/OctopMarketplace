# 销售数据分析专家

面向中小企业（尤其是以销售为主的企业）的销售数据分析专家。用户上传从 ERP、CRM、进销存、电商后台或 Excel 导出的销售明细，专家先识别字段和口径，再分析业绩、客户、产品、漏斗，并写成周报月报。不需要预先整理数据，也不需要连接外部系统。

回应 [TencentCloud/Octop#2923](https://github.com/TencentCloud/Octop/issues/2923)：希望预置开箱即用的企业数据业务分析专家，降低非技术团队的使用门槛。

## 技能

| 技能 | 内容 |
| --- | --- |
| `sales-data-intake` | 读表、数据画像、字段识别、清洗（重复、退货、测试单）、口径确认 |
| `sales-performance` | 趋势、同比环比、目标达成与时间进度、排名、集中度、变动归因 |
| `sales-customer-analysis` | RFM 八类分层、客户集中度、新老客户、复购率、流失预警 |
| `sales-product-mix` | ABC 分类、毛利与毛利率、量价结构拆分、滞销识别 |
| `sales-pipeline-forecast` | 商机阶段分布与转化、成交周期、进度推算、加权漏斗预测 |
| `sales-report` | 销售日报、周报、月报，Excel 汇总与图表，定期报告 |

## 计算脚本

`skills/sales-data-intake/scripts/datakit.py` 只依赖 Python 标准库（读 `.xlsx` 需要 `openpyxl`），把容易算错的部分固定下来：

- `profile`：数据画像。跳过导出文件的标题行，识别 UTF-8 / GBK 编码，把"￥1,200""12%""(300)"识别为数字。
- `rfm`：按订单号去重计算 R、F、M，以均值划分八类客户，可导出逐客户 CSV。
- `variance`：两期之间按某个维度做变动归因；给出数量列时拆成销量、结构、价格、新增、停售五部分，五部分之和等于总变动。

## 说明

- 本专家为原创内容，未改编第三方技能包。
- 分析结论依赖用户提供的数据和口径；涉及提成、考核等个人收入的结论，专家会提示按公司制度复核。
